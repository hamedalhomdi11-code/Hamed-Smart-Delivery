# Accepted requirements

- Product name: Hamed Smart Delivery (حامد سمارت دليفري).
- Android app, Arabic and English, RTL/LTR.
- Driver-first dark interface with smooth but restrained motion.
- Dynamic search action: start searching, then mark an order received.
- Navigation is the primary product capability; remote assistant control is optional.
- Manual and remote commands share one validated state machine.
- Offline-first local operation with safe revalidation of queued remote commands.
- Restaurant ranking must distinguish observed order history from public signals; never invent live demand.
- Do not store customer personal data.
- Live maps, GPS tracking, overlays, backend and production APK require implementation and device testing.
